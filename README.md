# When Mira Calls - The Game

When Mira Calls is a narrative adventure game that teaches CyberSecurity concepts to 11 - 13 year olds through an interactive story in which a young protagonist is searching for their missing aunt. While uncovering clues across three interconnected worlds, players learn key concepts in detecting scams, managing their digital footprints, and understanding social engineering and the permanence of the internet. 


## Play Online (Web Browser)

Play 'When Mira Calls' at [whenmiracalls.com](https://whenmiracalls.com/)

### Play Locally

```
$ npm install
$ npm build
$ npm run dev
```
